# Cello Coach — MVP 0.1

Локальное веб-приложение для тренировки интонации на виолончели.

## Что уже умеет

- загружать несжатый MusicXML (`.musicxml` / `.xml`);
- показывать партитуру через OpenSheetMusicDisplay;
- слушать микрофон в браузере;
- определять высоту звука в диапазоне, подходящем для виолончели;
- сравнивать сыгранную ноту с ожидаемой в центах;
- переходить к следующей ноте после чистого удержания;
- настраивать допуск, время удержания и A4;
- показывать простую статистику сессии;
- тестировать механику без микрофона.

## Как запустить на Windows

Микрофон в современном браузере работает только в secure context: HTTPS или `localhost`.

### Вариант 1 — если установлен Python

1. Открой PowerShell в папке приложения.
2. Выполни:

   `python -m http.server 8080`

3. Открой в Chrome/Edge:

   `http://localhost:8080`

### Вариант 2 — VS Code

Открой папку в VS Code и запусти её через расширение Live Server.

## Как подготовить «В непогоду»

Открой ноты в MuseScore (или другом нотном редакторе) и экспортируй именно партию виолончели как **MusicXML**, лучше несжатый `.musicxml`.

## Ограничения MVP

- `.mxl` пока не распаковывается;
- анализируется первая партия и одна мелодическая линия;
- двойные ноты/аккорды пока игнорируются;
- переход курсора OSMD и внутренний список нот могут слегка расходиться на сложных паузах, форшлагах, нескольких голосах и связках;
- распознавание сделано простым realtime autocorrelation-алгоритмом. Для стабильной работы с настоящей виолончелью его стоит улучшить отдельной обработкой атаки смычка, вибрато, гармоник и шумов комнаты.

## Следующая версия

Приоритетные улучшения:

1. импорт `.mxl`;
2. точное сопоставление каждой MusicXML-ноты с графическим курсором;
3. устойчивый pitch tracker (McLeod/YIN + сглаживание);
4. режим «фраза», где оцениваются несколько нот подряд;
5. карта проблемных тактов и нот;
6. запись истории занятий;
7. установка как PWA на телефон.
