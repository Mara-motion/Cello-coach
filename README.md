# Cello Coach — mobile v0.3

Мобильный прототип тренажёра интонации для виолончели, подготовленный под «В непогоду» Г. Гольтермана.

## Главное отличие v0.3

Фотографии партитуры **не лежат в репозитории**. Пользователь выбирает их из галереи телефона, после чего они сохраняются локально в IndexedDB браузера. Никакой серверной загрузки фотографий в приложении нет.

## Что умеет

- работает на телефоне по HTTPS через GitHub Pages;
- просит доступ к микрофону;
- старается отключить echo cancellation / noise suppression / auto gain control;
- определяет высоту звука в реальном времени;
- показывает отклонение от целевой ноты в центах;
- автоматически переходит дальше после чистого удержания;
- позволяет один раз «обучить» каждую строку медленным проигрыванием;
- исправляет ошибочно распознанную ноту на полутон или октаву;
- хранит фото и разметку локально;
- экспортирует/импортирует разметку JSON;
- устанавливается как PWA на поддерживаемых телефонах;
- после первого открытия может работать офлайн (кроме самой первой загрузки сайта).

## Как выложить на GitHub Pages с телефона или ПК

1. Распакуй ZIP.
2. Открой репозиторий `Cello-coach` на GitHub.
3. Нажми **Add file → Upload files**.
4. Загрузи **все файлы из этой папки в корень репозитория**:
   - `index.html`
   - `styles.css`
   - `app.js`
   - `manifest.webmanifest`
   - `sw.js`
   - `icon-192.png`
   - `icon-512.png`
   - `README.md`
5. Нажми **Commit changes**.
6. Открой **Settings → Pages**.
7. В `Build and deployment` выбери **Deploy from a branch**.
8. Branch: `main`, folder: `/ (root)` → **Save**.
9. Через минуту-две GitHub покажет ссылку вида `https://mara-motion.github.io/Cello-coach/`.
10. Открой её на телефоне и разреши микрофон.

## Первый тест

Не обучай сразу всю пьесу. Достаточно первой строки. Если pitch detector путается, сделай скрин раздела «Точность и диагностика» во время игры — там видны распознанная нота, частота и уверенность.

## Приватность

В репозитории нет фотографий пользователя. Они сохраняются только в локальном хранилище браузера на устройстве. Очистка данных сайта в браузере удалит эти фотографии.
