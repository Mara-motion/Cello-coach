# Cello Coach Mobile v0.6.1 — авто-follow beta

Мобильный прототип тренажёра интонации для виолончели на материале Г. Гольтермана «В непогоду» (Schlechtes Wetter, Op. 104 №3).

## Что нового в 0.6.1

- сохранён стабильный YIN-тюнер из 0.5;
- добавлен тестовый режим автоследования по первым 12 нотным позициям;
- после чистого попадания приложение само переходит к следующей позиции;
- отдельное «обучение строки» не требуется;
- неоднозначные на скане знаки альтерации приложение разрешает при первом прохождении и запоминает локально на телефоне;
- есть Назад, Пропустить, Сначала и сброс запомненных знаков;
- ручной тюнер остаётся доступен отдельным режимом.

## Как обновить GitHub Pages

Загрузить все файлы из этой папки поверх файлов в корне репозитория `Cello-coach`, затем Commit changes.
После успешного Pages deployment открыть сайт с `?v=6` в конце URL.

## Важно

Первые 12 позиций — тест механики «сыграла чисто → дальше». После проверки UX последовательность можно расширить на системы и всю пьесу.


## Исправление 0.6.1

- устранена задержка после засчитанной ноты: история медианного сглаживания теперь очищается при переходе к следующей;
- в режиме пьесы подтверждение ноты сокращено до ~95 мс (ручной тюнер сохраняет выбранное пользователем значение);
- анализ в режиме пьесы обновляется чаще — примерно каждые 55 мс.
