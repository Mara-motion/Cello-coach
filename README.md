# Cello Coach Mobile v0.5 — stable tuner

Исправление тюнера для виолончели.

## Что исправлено
- старый autocorrelation-детектор заменён на YIN;
- добавлено медианное сглаживание по нескольким кадрам;
- краткие скачки на обертоны/субгармоники отбрасываются;
- добавлен high-pass / low-pass фильтр для телефонного микрофона;
- окно анализа увеличено до 8192 отсчётов для низкого регистра виолончели;
- очень далёкие ошибочные значения больше не показываются как `−1900¢`: вместо этого отображается распознанная нота;
- в диагностике видны сырой и сглаженный сигнал.

## Обновление GitHub Pages
Замените файлы в корне репозитория файлами из этого архива и сделайте Commit.

Service Worker использует новый cache key `cello-coach-mobile-v05`. Если старая версия всё равно открывается, откройте сайт с `?v=5` в конце адреса и обновите страницу.

## Что проверить
1. A3 (220 Гц) длинным смычком 5–10 секунд.
2. Открытые струны C2, G2, D3, A3.
3. Сделать скрин блока «Точность и диагностика», если показания всё ещё скачут.
