# Cello Coach Mobile v0.4 — clean score

Версия для мобильного теста с чистой печатной партитурой «Schlechtes Wetter / В непогоду» Г. Гольтермана, Op.104 №3.

## Что изменилось
- убрана обязательная загрузка фотографий;
- убрана автоматическая нарезка фотографий на строки;
- убран обязательный режим «обучить строку»;
- добавлен просмотр чистой партитуры из открытого PDF-источника;
- сохранён мобильный тюнер и проверка интонации через микрофон;
- целевую ноту можно выбрать вручную для проверки качества распознавания.

## Обновление GitHub Pages
Замените файлы в корне репозитория файлами из этого архива и сделайте Commit. GitHub Pages обновится автоматически.

## Источник партитуры
TheCellist.ru, PDF: cp-Goltermann-G.-Stormy-Weather.pdf

Примечание: сам PDF загружается с внешнего сайта и поэтому для просмотра партитуры требуется интернет. Если мобильный Chrome не показывает PDF во встроенном окне, используйте кнопку «Открыть партитуру отдельно».
